# Engineering at Tonkin + Taylor

Welcome to the open-source home of T+T's software and data engineering teams. We build tools that bridge the gap between physical infrastructure and digital intelligence.

## 🛠 Our Technical Focus

We specialise in creating robust solutions for the AEC (Architecture, Engineering, and Construction) industry. Our core domains include:

- **Geospatial Analysis:** Automating terrain and site assessments.
- **Geotechnical Data:** Standardising how we handle ground-model data.
- **AI & Automation:** Deploying LLMs and agents to streamline technical document review.
